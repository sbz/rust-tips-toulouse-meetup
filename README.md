# rust-tips-toulouse-meetup

# Requirements

Install [marp-cli](https://github.com/marp-team/marp-cli)

# Build

- Generate PDF

```bash
make pdf
```

- Display PDF to present

It assumes you have [mupdf](https://github.com/ArtifexSoftware/mupdf) installed
or edit the `Makefile` with `xdg-open`

```bash
make open
```
